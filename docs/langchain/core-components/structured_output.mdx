# 结构化输出（Structured output）

结构化输出允许Agent以特定的、可预测的格式返回数据。与解析自然语言响应不同，可以获得应用程序可以直接使用的JSON对象、
Pydantic模型或数据类（dataclass）的结构化数据。

Agent的结构化输出，通过create_agent函数的response_format签名。源码片段如下：

```python
def create_agent(
    model: str | BaseChatModel,
    tools: Sequence[BaseTool | Callable[..., Any] | dict[str, Any]] | None = None,
    *,
    system_prompt: str | SystemMessage | None = None,
    middleware: Sequence[AgentMiddleware[StateT_co, ContextT]] = (),
    response_format: ResponseFormat[ResponseT] | type[ResponseT] | dict[str, Any] | None = None,
    state_schema: type[AgentState[ResponseT]] | None = None,
    context_schema: type[ContextT] | None = None,
    checkpointer: Checkpointer | None = None,
    store: BaseStore | None = None,
    interrupt_before: list[str] | None = None,
    interrupt_after: list[str] | None = None,
    debug: bool = False,
    name: str | None = None,
    cache: BaseCache[Any] | None = None,
    transformers: Sequence[TransformerFactory] | None = None,
) -> CompiledStateGraph[
    AgentState[ResponseT], ContextT, InputAgentState, OutputAgentState[ResponseT]
]


ResponseFormat = ToolStrategy[SchemaT] | ProviderStrategy[SchemaT] | AutoStrategy[SchemaT]
"""Union type for all supported response format strategies."""
```

response_format可以是：
- None：不使用结构化输出，默认值。
- dict[str, Any]：一个字典实例，通常是 Schema 字典，`{"type": "object", ...}`。key是字符串类型，
value可以是任意类型。
- type[ResponseT]：ResponseT是一个类型变量，属于类型的占位符，类似Java中的泛型T。由用户输入决定，例如用户
传入response_format=User，则ResponseT就是User，而type[User]表类对象`<class 'User'>`。
- ResponseFormat[ResponseT]：ResponseFormat是一个联合类型，有三种策略类型：
  - ToolStrategy[SchemaT]：基于“工具调用”的策略。将你提供的 Schema 转换成一个“函数工具”。它通过引导模型调用这个工具（并将结构化数据作为参数传入）来获取结果，
  然后由 Agent 从工具调用中提取并验证数据。
  - ProviderStrategy[SchemaT]：基于“模型原生能力”的策略。ProviderStrategy 直接利用模型提供商
  （如 OpenAI、Anthropic）API 层面原生的结构化输出功能。模型会直接生成符合指定 JSON Schema 的响应，无需经过工具调用的中间步骤。
  - AutoStrategy[SchemaT]：自动选择的“智能”策略。本身不执行具体逻辑，而是一个占位符或包装器。它的作用是让 LangChain 在创建 Agent 时，
  根据当前模型的能力自动选择使用 ProviderStrategy 还是 ToolStrategy。


### 提供商策略（Provider strategy）

ProviderStrategy源码片段
```python
@dataclass(init=False)
class ProviderStrategy(Generic[SchemaT]):
    """Use the model provider's native structured output method."""

    schema: type[SchemaT] | dict[str, Any]
    """Schema for native mode."""

    schema_spec: _SchemaSpec[SchemaT]
    """Schema spec for native mode."""
```

ProviderStrategy中定义结构化输出格式的schema。支持:
- Pydantic模型：带字段验证的BaseModel子类。返回经过验证的Pydantic实例。
- 数据类（Dataclasses）：带有类型注解的Python数据类。返回dict类型。
- TypedDict：类型化字典类。返回dict类型。
- JSON模式（JSON Schema）：具有JSON模式规范的字典。必须包括顶级标题title和描述description键。返回dict类型。

TypedDict和JSON Schema的区别：

定义一个 User，包含 name: str、age: int、可选 email。

TypedDict写法：
```python
from typing import TypedDict, NotRequired

class User(TypedDict):
    name: str
    age: int
    email: NotRequired[str]
```

等价的 JSON Schema 写法：
```python
{
    "title": "User",
    "description": "A user profile",
    "type": "object",
    "properties": {
        "name":  {"type": "string"},
        "age":   {"type": "integer"},
        "email": {"type": "string"}
    },
    "required": ["name", "age"]
}
```

```python
from model_identifiers import qwen2dot5_7b_identifier
from langchain.agents import create_agent
from langchain.agents.structured_output import ProviderStrategy

contact_info_schema = {
    "title": "ContactInfo",
    "type": "object",
    "description": "Contact information for a person.",
    "properties": {
        "name": {"type": "string", "description": "The name of the person"},
        "email": {"type": "string", "description": "The email address of the person"},
```

### 工具策略（Tool strategy）
对于不支持原生结构化输出的模型，LangChain使用工具调用来实现相同的结果。这适用于所有支持工具调用的模型（大多数现代模型）。

源码片段：
```python
@dataclass(init=False)
class ToolStrategy(Generic[SchemaT]):
    """Use a tool calling strategy for model responses."""

    schema: type[SchemaT] | UnionType | dict[str, Any]
    """Schema for the tool calls."""

    schema_specs: list[_SchemaSpec[Any]]
    """Schema specs for the tool calls."""

    tool_message_content: str | None
    """The content of the tool message to be returned when the model calls
    an artificial structured output tool.
    """

    handle_errors: (
        bool | str | type[Exception] | tuple[type[Exception], ...] | Callable[[Exception], str]
    )
```

#### 模式schema
ToolStrategy中定义结构化输出格式的schema。支持:Pydantic models、Dataclasses、TypedDict和JSON Schema，还支持
- Union types：多个模式选项。模型将根据上下文选择最合适的模式。例如：Union[ProductReview, CustomerComplaint]。

tool_message_content表示生成结构化输出时返回的工具消息的自定义内容。如果未提供，则默认为显示结构化响应数据的消息。

###### 处理多种异常类型
- 如果handle_errors是异常类型，则Agent只会在引发的异常是指定类型时重试（使用默认错误消息）。
在所有其他情况下，将引发异常。
- 如果handle_errors是一个异常元组，则Agent只会在引发的异常是指定类型之一时重试（使用默认错误消息）。
在所有其他情况下，将引发异常。

```python
# 单个异常. 在出现ValueError时，模型会重试.
response_format=ToolStrategy(schema=ProductRating,
                                 handle_errors=(ValueError)  # Retry on ValueError
                                 )

# 多个异常. 在出现ValueError和TypeError时，模型会重试。
response_format=ToolStrategy(schema=ProductRating,
                                 handle_errors=(ValueError, TypeError)  # Retry on ValueError and TypeError
                                 )

```

##### 模型拒绝（Model refusal）
当模型拒绝时，它不会返回任何结构化输出。使用ProviderStrategy，Agent会引发StructuredOutputValidationError。
使用ToolStrategy，Agent结束时没有structured_response。
要为任何一种策略引发ModelRefusalError，添加ModelRefusalMiddleware：

```python
from langchain.agents.structured_output import ToolStrategy
from pydantic import BaseModel, Field
from langchain.agents import create_agent
from langchain.agents.middleware import ModelRefusalMiddleware
from model_identifiers import qwen2dot5_7b_identifier


class ProductRating(BaseModel):
    rating: int | None = Field(description="Rating from 1-5", ge=1, le=5)
    comment: str = Field(description="Review comment")


agent = create_agent(
    model=qwen2dot5_7b_identifier,
    response_format=ToolStrategy(ProductRating),
    system_prompt="You are a helpful assistant that parses product reviews. "
                  "Do not make any field or value up. "
                  "Please refuse to parse.",

    middleware=[ModelRefusalMiddleware()]
)

response = agent.invoke({
    "messages": [{"role": "user", "content": "Parse this: Amazing product, 10/10!"}]
})

    message.pretty_print()
```

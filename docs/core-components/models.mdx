# 模型
LLM（大语言模型，Large Language Model）是强大的人工智能工具，可以像人类一样解释和生成文本。他们足够多才多艺，可以写内容、翻译语言、总结和回答问题，而不需要针对每个任务进行专门的培训。

除了文本生成，许多模型还支持：
- 工具调用（Tool calling）：调用外部工具（如数据库查询或API调用）并在其响应中使用结果。
- 结构化输出（Structured output）：其中模型的响应被限制为遵循已定义的格式。
- 多模态性（Multimodality）：处理和返回文本以外的数据，如图像、音频和视频。
- 推理（Reasoning）：模型执行多步推理来得出结论。

Model是Agent的推理引擎。它们驱动Agent的决策过程，决定调用哪个工具，如何解释结果，以及何时提供最终答案。

选择的Model的质量和功能直接影响Agent的基线可靠性和性能。不同的Model擅长于不同的任务——有些更擅长于遵循复杂的指令，有些擅长结构化推理，有些支持更大的上下文窗口来处理更多的信息。

LangChain的标准模型接口可以访问许多不同的提供商集成，这使得在模型之间进行试验和切换以找到最适合用例的模型变得容易。

模型可以以两种方式使用：
- 与Agent一起使用——在创建Agent时可以动态指定模型。
- 独立使用——模型可以被直接调用来完成文本生成、分类或提取等任务，而不需要Agent框架。

相同的模型接口可以在两种上下文中工作，这使得可以灵活地根据需要从简单的工作流开始，然后扩展到更复杂的基于代理的工作流。


## 初始化模型

```python
from langchain.chat_models import init_chat_model

model = init_chat_model(model="ollama:qwen2.5:7b")
response = model.invoke(input="Why do parrots talk?")
print(response)
```
代码说明：
- 通过langchain.chat_models的init_chat_model初始化模型，传入参数名为model，值为一个字符串，对于Ollama提供商的模型需要显示写ollama。
- 初始化好的model，通过invoke触发模型行为，模型返回结果为response。

LangChain通过专门的集成包支持所有主要的模型提供商。每个提供商包实现相同的标准接口，因此可以在不重写应用程序逻辑的情况下交换提供商。
新的模型名可以立即工作——不需要更新LangChain——因为提供商包将模型名直接传递给提供商的API。

聊天模型接受可用于配置其行为的参数。支持的完整参数集因模型和提供商而异，但标准参数包括：
- model
  - 参数类型：string，是否必须：是。
  - 含义：与提供商一起使用的特定模型的名称或标识符。可以使用“:”格式在单个参数中指定模型及其提供商，例如“openai:o1”。
- api_key
  - 参数类型：string，是否必须：否。
  - 含义：与模型的提供商进行身份验证所需的密钥。这通常是在注册访问模型时发出的。通常通过设置环境变量来访问。对于Ollama，无需api_key。
- temperature
  - 参数类型：number，是否必须：否。
  - 含义：控制模型输出的随机性。数字越高，回答越有创意；较低的值使它们更具确定性。
- max_tokens
  - 参数类型：number，是否必须：否。
  - 含义：限制响应中的token总数，有效地控制输出的长度。
- timeout
  - 参数类型：number，是否必须：否。
  - 在取消请求之前等待模型响应的最大时间（以秒为单位）。对于不可靠的网络，可适当增大该参数的值。
- max_retries
  - 参数类型：number，是否必须：否，默认值：6。
  - 含义：如果由于网络超时或速率限制等问题导致请求失败，系统将尝试重新发送请求的最大次数。重试使用带抖动的指数回退。网络错误、速率限制（429）和服务器错误（5xx）会自动重试。
  客户端错误401（未授权）或404等不会重试。对于不可靠网络上长时间运行的代理任务，请考虑将此值增加到10-15。

```python
from langchain.chat_models import init_chat_model

model = init_chat_model(
    model="ollama:qwen2.5:7b",
    temperature=0.7,
    timeout=30,
    max_tokens=1000,
    max_retries=6,  # Default; increase for unreliable networks
)
response = model.invoke(input="Why do parrots talk?")
print(response)
```

## 调用模型


必须调用模型来生成输出。有三种主要的调用方法，它们分别是invoke()，stream()，batch()。每种方法适用于不同的用例。

### Invoke
调用模型最直接的方法是对单个消息（Message）或消息列表使用invoke()方法。在前面章节已经演示过。
可以向模型提供消息列表，以表示会话历史记录。每个消息都有一个角色，模型使用该角色来指示谁在对话中发送了消息。

代码如下：
```python
from langchain.chat_models import init_chat_model

model = init_chat_model(model="ollama:qwen2.5:7b")

response = model.invoke(input="Why do parrots have colorful feathers?")
print("response of single message:\n", response)

conversation = [
    {"role": "system", "content": "You are a helpful assistant that translates English to French."},
    {"role": "user", "content": "Translate: I love programming."},
    {"role": "assistant", "content": "J'adore la programmation."},
    {"role": "user", "content": "Translate: I love building applications."}
]

response = model.invoke(input=conversation)
print("response of message list:\n",response)  # AIMessage("J'adore créer des applications.")

from langchain.messages import HumanMessage, AIMessage, SystemMessage

conversation = [
    SystemMessage("You are a helpful assistant that translates English to French."),
    HumanMessage("Translate: I love programming."),
    AIMessage("J'adore la programmation."),
    HumanMessage("Translate: I love building applications.")
]

response = model.invoke(input=conversation)
print("response of message list using Message Object:\n",response)  # AIMessage("J'adore créer des applications.")
```

代码说明：
- 第一个conversation是一个Json列表，每个Json指定了角色role和内容content，role有system、user和assistant。
  - system（系统）：给模型设定“人设”或“全局规则”。它通常放在对话的最开头，用来告诉模型它的身份是什么、应该遵循什么指令。比如你例子中的 "You are a helpful assistant that translates English to French."，就是告诉 AI：“你是一个负责把英文翻译成法文的助手”，这样 AI 之后的所有回复都会围绕这个设定展开。
  - user（用户）：代表你（也就是发起对话的人）。用户向模型发送消息，比如 "Translate: I love programming." 就是你向模型发出的具体指令。
  - assistant（助手）：代表模型之前已经回复过的内容。它的作用是提供“上下文”，让模型知道之前的对话进展到了哪一步，从而能更连贯地回答后续问题。比如你例子中 AI 回复了 "J'adore la programmation."，这条记录就会被标记为 assistant。
  简单来说，system 定规矩，user 提问题，assistant 记回答。
- 第二个conversation使用了LangChain内置的消息对象：SystemMessage、HumanMessage和AIMessage，分别对应第一个conversation的system、user和assistant三个角色，两个conversation是等价的。后面章节将详细介绍Message。
- 三种方式均可通过invoke()方法的input参数传入来调用模型。
- invoke()返回的是一个AIMessage对象。

### Stream
大多数模型可以在生成输出内容时流式传输输出内容。通过逐步显示输出，流式显著改善了用户体验，特别是对于较长的响应。

调用stream()将返回一个迭代器Iterator[AIMessageChunk]，该迭代器在产生输出块时可以立即输出块。可以使用一个循环来实时处理每个块。

代码如下：
```python
from langchain.chat_models import init_chat_model

model = init_chat_model(model="ollama:qwen2.5:7b")

for chunk in model.stream("Why do parrots have colorful feathers?"):
    print(chunk.text, end="|", flush=True)

print("\n----------")
full = None  # None | AIMessageChunk
for chunk in model.stream("What color is the sky?"):
    full = chunk if full is None else full + chunk
    print(full.text, end="|\n")
print("----------")
if full:
    print(full.content_blocks)
```

### Batch
将一组独立的请求作为一个批（Batch）发送到一个模型中可以显著提高性能并降低成本，因为处理可以并行完成。
可以通过调用batch()来实现。

默认情况下，batch()将只返回整个批处理的最终输出。
如果想在每个单独的输入完成生成时接收输出，可以使用batch_as_completed()对结果进行流处理。

当使用batch_as_completed()时，结果可能会乱序到达。每个都包含用于匹配的输入索引，以便根据需要重建原始顺序。

代码如下：
```python
from langchain.chat_models import init_chat_model
from langchain_core.runnables import RunnableConfig

model = init_chat_model(model="ollama:qwen2.5:7b")

responses = model.batch(inputs=[
    "Why do parrots have colorful feathers?",
    "How do airplanes fly?",
    "What is quantum computing?"
],config=RunnableConfig(max_concurrency=5))
for response in responses:
    print(response)

for response in model.batch_as_completed([
    "Why do parrots have colorful feathers?",
    "How do airplanes fly?",
    "What is quantum computing?"
]):
    print(response)
```
